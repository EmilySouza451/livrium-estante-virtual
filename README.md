# 📚 Livrium • Estante Virtual & Ex Libris

> *Seu santuário literário pessoal para registrar leituras, acompanhar o progresso página a página e cultivar desafios enriquecedores.*

O **Livrium** é um aplicativo voltado para organização de leituras e incentivo ao hábito literário. Desenvolvido com React e Tailwind CSS, combina facilidade de uso com a atmosfera aconchegante e clássica de bibliotecas tradicionais (*Nostalgic Library*).

---

## ✨ Principais Funcionalidades

- 📅 **Calendário Literário:** Grade visual onde cada dia é preenchido pela capa da obra lida e minutos de foco dedicados.
- 📊 **Estatísticas & Análise Literária:** Métricas anuais, gráficos de leitura mês a mês e distribuição temática por gênero.
- 🏆 **Desafios e Gamificação:** Metas mensais, maratonas de páginas e conquistas comemorativas.
- 🖋️ **Diário Ex Libris:** Espaço exclusivo para registrar citações emblemáticas, notas de estudo e reflexões.
- 📖 **Cadastro com ISBN:** Preenchimento ágil com suporte a livros físicos, e-books e audiolivros.
- 📱 **Interface 100% Responsiva:** Adaptada para navegação confortável tanto no computador quanto no celular.
